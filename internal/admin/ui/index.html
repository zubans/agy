Опубликованные модели (`GET /v1/models`)

Клиентам в GET /v1/models и /v1/responses видны только модели из этого списка (собранные в конструкторе или опубликованные как отдельные модели из вкладки «Провайдеры»). При лимите на одном провайдере (связке провайдер + модель) он уходит в охлаждение (срок парсится из ответа, иначе по умолчанию), а запрос автоматически переходит на следующий доступный вариант по приоритету.

Подключённые провайдеры (воркеры и Ollama)

Воркер-контейнеры (agy-*, codex-*, claude-*, gemini-*) и remote-ollama по умолчанию скрыты из клиентского списка моделей (public=нет). Нажмите «Выбрать модели» на нужном провайдере, чтобы получить доступные модели и опубликовать их как отдельные модели, либо соберите пул в «Конструкторе».

Docker Compose и масштабирование пула

          
Инициализация (число контейнеров можно менять):
  make init
  make init CLAUDE_COUNT=2 CODEX_COUNT=3 GEMINI_COUNT=1 AGY_COUNT=6

Запуск и статус:
  make up
  make ps
  make agent-ls

Добавить / удалить контейнер на лету:
  make agent-add TYPE=agy COUNT=2
  make agent-add TYPE=codex
  make agent-rm NAME=agy-5
